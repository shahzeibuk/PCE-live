# Product Requirements Document (PRD)

## Pakistan Currency Exchange Website

**Tech Stack:** Next.js + Payload CMS + shadcn/ui
**Purpose:** Corporate website with dynamic currency rates, service pages, branch locator, and CMS-managed content.

---

# 1. Overview

## Objective

Build a modern, fast, and secure corporate website for a currency exchange company using:

* **Frontend:** Next.js (App Router)
* **Backend/CMS:** Payload CMS
* **UI System:** shadcn/ui
* **Database:** PostgreSQL (recommended with Payload)
* **Hosting:** Vercel / AWS / DigitalOcean

The website should allow **admins to manage all content from the CMS** while providing visitors with real-time currency information, service information, and branch locations.

---

# 2. Core Goals

1. Corporate presence
2. Display live currency exchange rates
3. Showcase services
4. Provide branch locator
5. Allow easy CMS content updates
6. SEO optimized
7. Fast performance
8. Mobile responsive
